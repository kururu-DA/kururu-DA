## 🚀 Featured AI Projects

### 🏥 AI Multi-Channel Clinic Assistant
> **Conversational AI that replaces app downloads with a WhatsApp/Telegram message**

Patients book clinic appointments in natural Arabic or English via WhatsApp and Telegram.
LLM-powered intent classification extracts doctor, specialty, date, and time from free text.
Single FastAPI backend — adding a new channel needs only a new adapter, zero core changes.

**Stack:** `Python` `FastAPI` `LangChain` `Claude API` `Telegram Bot API` `WhatsApp Cloud API` `SQLite`

---

### 📚 RAG Knowledge Base System
> **Document intelligence with a native mobile client**

End-to-end RAG pipeline: PDF ingestion → OpenAI embeddings → Supabase pgvector →
semantic search → cited LLM response. Flutter mobile client as the primary interface —
because most RAG demos are web-only.

**Stack:** `LangChain` `LlamaIndex` `OpenAI Embeddings` `Supabase pgvector` `FastAPI` `Flutter`

---

### 📱 On-Device AI Mobile App
> **AI inference at 8ms — no internet, no cloud costs, no latency**

TFLite model running inside a Flutter app. Benchmarked: on-device 8ms vs cloud API 750ms.
94× latency reduction. Works in airplane mode. Used as intent-classification fallback
for the clinic assistant in rural 3G environments.

**Stack:** `Flutter` `TFLite` `ML Kit` `HuggingFace` `Python` `PyTorch` `Core ML`

---

### ⚡ AI Healthcare Automation Pipeline
> **Zero-touch patient intake — from message to confirmed appointment**

n8n + VoiceFlow workflow: patient messages → LLM extracts details → record created →
Arabic WhatsApp confirmation sent → 24h reminder dispatched → post-visit sentiment
classified and routed. No human in the loop.

**Stack:** `n8n` `VoiceFlow` `OpenAI API` `WhatsApp Cloud API` `FastAPI` `PostgreSQL`
